VISUAL LEARNING · KUBERNETES

Kubernetes architecture, made clear.

A simplified view of how requests travel into a cluster and how the control plane manages workloads running on worker nodes.

kubernetes-cluster.svg
ARCHITECTURE OVERVIEW
Control plane components Worker node workloads Communication / control
01

Control plane

The API server exposes the Kubernetes API; etcd stores cluster state; the scheduler assigns Pods; controllers reconcile desired state.

02

Worker node

Kubelet ensures Pods run, the container runtime runs containers, and kube-proxy or the cluster's networking implementation supports Service traffic.

03

Workload & traffic

Deployments manage replicated Pods. Services provide stable access to matching Pods; Ingress or a Gateway can route external HTTP(S) traffic.

Learning diagram: simplified architecture. Exact networking and ingress components depend on the Kubernetes distribution and installed add-ons.
